# PR #220 : feat(209): web v1 UI harmonisation - session-aware account menu, a11y, error pages

- Date : 2026-11-24
- Branche : feat/209-harmonisation-ui
- Issue : #209 (milestone #12 « Web v1 — zones publiques & connexion OIDC »)
- Rapport : https://github.com/saucisson/petrichor/pull/220

## Contenu

- Menu compte du header piloté par `GET /auth/me` : « Se connecter » seul si
  anonyme (returnTo = page courante), nom + « Préférences » + « Se déconnecter »
  si connecté (`POST /auth/logout` puis retour à `/ui/`). `/auth/me` expose
  désormais `preferred_username`/`name` quand l'IdP les envoie (openapi.yaml +
  test Python épinglé).
- a11y : skip-link vers `#main` (landmark `main` unique), annonceur global
  `aria-live="polite"` narrant les changements de zone.
- Pages d'erreur en charte : portail atelier sans session (bouton unique
  « Se connecter avec auth.linard.fr », returnTo=/ui/atelier) et page 404
  pour les routes client inconnues sous `/ui/`.
- Zones en deep-liens (`/ui/`, `/ui/decouvrir`, `/ui/atelier`), navigation
  synchronisée via `history.replaceState`.
- 8 tests vitest neufs (`harmonisation.test.tsx`), mock `/auth/me` partagé,
  spec e2e landing mise à jour (portail), bundle rebuild et épinglé dans
  `test_ui.py`.
