# ADR-0022: Worklog as per-record files (worklog v2)

## Status

Accepted (drafted in the implementation PR, accepted by the human via the
session directive - part 3 of the brief).

## Context

`WORKLOG.md` was a single ~106 KB file, prepended by every PR in a format
learned by reading the file. Three costs: accidental reading of the
monolith by the agent, unbounded growth, rebase conflicts; plus a
duplication with the PR body (Changes, Testing evidence, Judgement calls).

## Decision

One file per record in `docs/worklog/`, human-facing only, generated by
the driver:

- `YYYY-MM-DD-pr-<N>.md`: one index card per pull request, generated by
  `make pr`, committed on the PR branch (`worklog: PR #N`).
- `YYYY-MM-DD-direct-<slug>.md`: one entry per direct commit on `daily`,
  created from `docs/worklog/_template.md` in the same commit.
- `archive-2026-11-12.md`: the old `WORKLOG.md`, archived unchanged.

No agent reads `docs/worklog/`. The evening audit goes through
`make day-report`.

## Consequences

- The monolith and its rebase conflicts are gone.
- All agent-side reading of the worklog is gone (context savings).
- The `make pr` driver generates the entry without agent intervention.
- Direct commits carry their template entry in the same commit.

## Precedence

This ADR takes precedence over the worklog clauses of ADR-0009, ADR-0010
and ADR-0017, as well as over any clause of the following constitutional
files that instructs writing or reading `WORKLOG.md`:

- `AGENTS.md` (honesty rules, session context, end-of-day audit)
- `docs/agents/developer.md` (reporting section, session continuity, recovery)
- `docs/agents/orchestration.md` (§3, §7, §8)
- `docs/branching.md` (end-of-day step)
- `docs/review-checklist.md` (§7)
- `.vibe/prompts/night-issue.md`, `.vibe/prompts/night-auto.md`

Human agreement: session directive of 2026-11-12 (part 3 of the brief),
which counts as explicit approval for this constitutional change.
