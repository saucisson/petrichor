# Maquette d'élicitation — Philosophes-3

**Référence des exigences frontend, pas du code de production.**

`philosophes-3.tsx` est la maquette de la session d'élicitation (scénario des
Philosophes-3). Elle définit les fonctions **P1–P12** reprises comme exigences
dans la spécification (`docs/spec/petrichor.md`). Le frontend réel est
implémenté ailleurs, branché sur l'API — ce fichier ne doit jamais être copié
tel quel dans le code applicatif.
