## Dialectes et examens supportés (MCC 2026)

TY a participé aux **13 examens** du MCC 2026 :

- **StateSpace** : génération du graphe des marquages
- **GlobalProperties** : ReachabilityDeadlock, QuasiLiveness, StableMarking, Liveness, OneSafe
- **UpperBounds** : calcul de bornes supérieures
- **Reachability** : ReachabilityCardinality, ReachabilityFireability
- **CTL** : CTLCardinality, CTLFireability
- **LTL** : LTLCardinality, LTLFireability

Cela couvre l'intégralité du spectre MCC — TY est un outil généraliste, pas spécialisé.

## CLI et interface

- **Non documentée publiquement.** TY est soumis au MCC en **forme binaire uniquement** (image disque VM `TY-2026.vmdk.tar.gz`), conformément aux règles du concours qui exigent une soumission binaire dans une machine virtuelle.
- Aucun dépôt GitHub public, aucune documentation CLI indexée. L'interface d'appel devra être inférée de l'image VM ou contactée directement auprès de Ferrite Technology.

## Licence et distribution

- **Licence non publique.** Ferrite Technology est une entité commerciale ; aucun site web public trouvé (`ferrite-tech.com`, `ferrite.tech` inexistants ou inaccessibles). La distribution se fait exclusivement via l'image VM du MCC, sans accès au code source.
- **Redistribution** : l'image VM `TY-2026.vmdk.tar.gz` est téléchargeable publiquement depuis le site du MCC, mais son utilisation en dehors du concours est soumise à la licence de Ferrite Technology, non précisée.

## Stabilité sur le benchmark

- TY a terminé les 25 389 exécutions du MCC 2026 sans crash signalé. Le taux de confiance de 99,674 % reflète des divergences de verdicts (pas des crashs), ce qui est rassurant pour la stabilité mécanique.
- **Historique** : absent du MCC 2025, présent en 2026 avec une participation complète (13/13 examens). Outil jeune, trajectoire à surveiller.

## Conclusion

**Intégrer TY comme 3ᵉ contre-vérificateur, avec réserves.**

| Critère | Évaluation |
|---|---|
| Couverture dialectale | Complète (tous les examens MCC) — point fort |
| Performance | 3ᵉ/4ᵉ systématiquement, loin derrière Tapaal et ITS-Tools — utilisable comme contre-vérificateur, pas comme moteur principal |
| Confiance | 99,674 % — légèrement inférieure aux leaders, à investiguer sur les cas de discordance |
| Licence | Non publique, distribution binaire seule — **blocker potentiel** pour une intégration pérenne (pas de source, pas de garantie de support) |
| Documentation | Aucune — CLI à reverse-engineer depuis l'image VM |

**Recommandation** : ouvrir une issue d'adaptateur TY (P28-follow-up) pour :
1. Extraire la CLI de l'image VM `TY-2026.vmdk.tar.gz` et documenter les appels par famille d'examen.
2. Contacter Ferrite Technology pour clarifier la licence d'utilisation hors MCC.
3. Si la licence le permet : qualifier TY sur le benchmark MCC (comme P22) avant de l'utiliser en contre-vérification.

Si la licence s'avère restrictive (non-commerciale, ou interdite hors MCC), la conclusion devient : **écarter TY**, la dégradation documentée étant alors « contre-vérification à 2 outils (Tapaal × ITS-Tools) ».
